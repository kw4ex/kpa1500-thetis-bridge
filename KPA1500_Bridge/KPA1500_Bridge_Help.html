1. What this istop

The KPA1500 bridge is a small program that runs on the PC next to Thetis. It connects Thetis, the Elecraft KPA1500 amplifier and (optionally) the Telepost LP-100A power meter over your network.

  • Follows your Thetis frequency, so the amplifier changes band by itself.
  • Standby on Tune: the amplifier drops to STANDBY while the radio tunes and goes back to what it was afterwards.
  • Shows live readings: forward and reflected power, SWR, drive, gain, temperature, volts and amps, fault codes, plus LP-100A readings.
  • Controls the amplifier: Operate/Standby, ATU inline/bypass/tune, antenna, clear fault, power on and off.
  • A control panel you open in a web browser, on this PC or any device on your network.
  • Keyboard commands in the bridge window.
  • Two ready-made Thetis windows (containers): KPA1500 Telemetry with meters, and KPA1500 Controls with buttons that light up. One double-click puts them into Thetis (see 16).
 Thetis  <--TCI-->  BRIDGE  <--LAN (UDP port 1500)-->  KPA1500 amplifier
   ^                  |  ^
   |  Multi Meter I/O |  +-- LP-100A (USB / COM port)
   +------------------+
                      |
              Browser panel  (http://127.0.0.1:8080)
The bridge never keys your transmitter. You press TUNE or PTT in Thetis as usual.

3. Installingtop

  1. Install Python. Go to python.org/downloads, install the latest Python 3, and tick Add python.exe to PATH on the first screen. Check it: open Command Prompt and type py --version.
  2. Make a folder C:\RadioScripts\KPA1500_Thetis_Bridge and copy kpa1500_thetis_bridge.py and start_kpa_bridge.bat into it.
  3. LP-100A only: in Command Prompt type py -m pip install pyserial.
  4. Test the program (no radio or amplifier needed): type cd C:\RadioScripts\KPA1500_Thetis_Bridge then py kpa1500_thetis_bridge.py --selftest. The last line should say ALL TESTS PASSED.
  5. Switch on TCI in Thetis. In Thetis open Setup > Serial/Network/Midi CAT (Network tab) and make sure the TCI server is running. The usual address is 127.0.0.1 port 50001.
  6. First run in safe mode: py kpa1500_thetis_bridge.py --dry-run. Nothing is sent to the amplifier. The status line should show TCI:ok AMP:ok.
  7. If Windows asks about the firewall, allow Python on Private networks.
  8. Run it for real: double-click start_kpa_bridge.bat, then open http://127.0.0.1:8080 in a browser.

If your amplifier is not at 192.168.0.175, open start_kpa_bridge.bat in Notepad and add --amp-ip 192.168.0.xxx to the BRIDGE_FLAGS line (see Customizing). Not sure of the address? Use --amp-ip auto, or see Finding the amplifier on the network.

4. Starting and stoppingtop

  • Double-click start_kpa_bridge.bat. It starts the bridge in its own window and never starts a second copy.
  • That window is minimized by default: look for KPA1500 Bridge on the taskbar.
  • Stop it by clicking its window and pressing Ctrl+C, or press Q in the window.
  • Start with Windows, or start Thetis and the bridge together: the notes at the top of start_kpa_bridge.bat explain both, step by step.

5. Finding the amplifier on the networktop

If you do not know the amplifier's IP address, the bridge can search for it. It sends the amplifier's own 'identify' command to every address on your network and lists the ones that answer. Each result shows the address, serial number and firmware.

  • Once, from the command line: py kpa1500_thetis_bridge.py --discover. It prints what it found and the address to use.
  • Every start: use --amp-ip auto. If the amplifier answers at the last known address nothing is searched; otherwise the network is searched and the address is remembered.
  • While running, in the panel: click Settings, then Find amplifier. Pick the one you want and press Use this address.
  • While running, in the bridge window: press D.

The address you pick is saved and used at the next start. An explicit --amp-ip 192.168.x.x in the batch file always overrides the saved one, so remove it if you want the panel's choice to stick.

By default it searches this PC's own network (the /24 around its address) and the network of the address it already knows. To search somewhere else give the network, for example --discover 192.168.1.0/24 or --discover-net 192.168.1.0/24.

The amplifier must be on and on the same network, and Windows Firewall must allow Python on Private networks. A sleeping amplifier may not answer. The amplifier address cannot be changed while the radio or amplifier is transmitting.

Panel password (Settings > Panel access): the bridge computer itself never needs the password. There you can Set password or Remove password at any time - so a forgotten password is never a problem: open http://127.0.0.1:8080 on the bridge computer and remove or change it. A password set or removed in the panel wins over --web-token in the start file.

8. Standby on Tunetop

When you press TUNE in Thetis, the bridge puts the amplifier in STANDBY. When TUNE ends it puts the amplifier back as it was: OPERATE returns to OPERATE, and an amplifier that was already in STANDBY stays there. Each step is read back and confirmed in the window.

  • Switch it on or off with the SOT tile, the S key, or --no-standby-on-tune.
  • If the connection to Thetis drops during a tune, the amplifier is left in STANDBY on purpose (fail-safe). Set OPERATE yourself afterwards.
With Thetis' own TUNE button, the standby command is sent when Thetis announces TUNE. A few milliseconds of RF can reach the amplifier first. Use the bridge TUNE button below to avoid that, keep tune power low, and keep your usual hardware protection.

The bridge TUNE button (recommended) - in the Thetis Controls window, the browser panel, or key T in the bridge window. It does things in the safe order:

  1. Checks: Thetis is connected, nothing is transmitting, and no 'no antenna?' warning is showing (press DUMMY OK first when a dummy load is connected).
  2. With Standby-on-Tune on and the amp in OPERATE: puts the amp in STANDBY and reads it back. If STANDBY is not confirmed, nothing is keyed and the reason is shown.
  3. Waits 0.1 s for the amp's relays, then tells Thetis to TUNE.
  4. The button lights and reads STOP TUNE (the panel also shows the seconds left). Press it to stop, or stop TUNE in Thetis.
  5. When the tune ends the amp goes back to OPERATE if it was in OPERATE (or stays in STANDBY if the 'no antenna?' hold applies).

Auto-stop: a tune started with the bridge TUNE button stops by itself after 20 s (change it in Settings > Safety; 0 = never). The bridge never changes the tune power: set it in Thetis as usual. With Standby-on-Tune off, TUNE leaves the amp as it is.

9. No antenna? check (receive level)top

With no antenna connected (antenna switch in the wrong place, a cable off, a relay fault) the receiver hears almost nothing: on a typical setup about -119 dBm, while a real antenna on 80 m shows -78 dBm or more of band noise. The bridge watches the receive level that Thetis reports and warns you before you transmit into nothing.

  • Thetis sends its average signal level of RX1 over TCI. The bridge takes the middle value of the last 2.5 seconds of receive, ignores the first 1.5 seconds after a band change or after transmitting, and ignores everything while transmitting (the verdict from just before key-up is kept).
  • If Thetis is not running, or it sends no level, the check does nothing and shows "no level from Thetis" in Settings. It never warns without a live reading.
  • Each band has its own limit. Below the limit means "no antenna?". The warning clears when the level is 3 dB above the limit again.
Band (m)Default limit
160, 80, 60, 40-105 dBm
30, 20-112 dBm
17, 15, 12, 10-115 dBm (quiet high bands read low even with a good antenna)
6off (no check)

What you see when the level is too low:

  • Browser panel: an orange bar across the top: NO ANTENNA? with the level, the band and the limit, and a DUMMY OK button. The RX tile turns red.
  • Thetis windows: a red line near the bottom of both windows, for example ANTENNA? RX -119 dBm (40m limit -105). The green AMP line also shows the receive level.
  • Bridge window: the status line ends with RX -119 ANTENNA?, and the log says why.
  • If you transmit anyway: the bar turns red and flashes, the Thetis line changes to !! TX - NO ANTENNA? CHECK DUMMY LOAD !!, and the bridge window beeps and logs a warning.

DUMMY OK (panel button, Thetis Controls button, key M): press it when a dummy load is connected on purpose. The warning is silenced for that band. DUMMY OK switches itself off as soon as a normal receive level comes back (antenna reconnected), so it can never be left on by mistake. Press it again to undo.

Keep the amp in STANDBY (optional): in Settings choose Warn and keep the amp in STANDBY. While the warning shows, the bridge puts the amplifier in STANDBY and refuses OPERATE. The radio can still transmit at low power straight through the amp. Pressing DUMMY OK, or a normal receive level returning, puts the amp back in OPERATE. The bridge never switches the amp while RF is present.

Settings (browser panel > Settings > No antenna? check, or key R in the bridge window): switch the check on or off, choose warn only or keep STANDBY, type a limit for each band (empty = no check on that band), or Learn this band: disconnect the antenna (or switch the radio to no antenna), wait 3 seconds, press Learn. The limit becomes the measured level + 6 dB. Default limits puts them all back. Everything is saved in kpa1500_settings.json and kept when you update.

Things that lower the receive level and can give a false warning: the receive attenuator (ATT / step attenuator), preamp off on the high bands, a very narrow filter, a small receive antenna, or a dead band at night on 10-17 m. Use Learn or set a lower limit for that band. This check is a reminder, not a protection device: keep the amplifier's own SWR protection and your usual care.

10. Tuning the amplifier's ATUtop

  1. Set the radio to the frequency you want and its power low.
  2. Press ATU TUNE (panel), or send KPA_ATU_TUNE from a Thetis button.
  3. Press TUNE in Thetis. That gives the amplifier a carrier to tune on.
  4. Release TUNE when the amplifier finishes. Cancel tune stops it early.

The bridge starts the amplifier's own tuning only. It never keys the transmitter.

11. Fan speedtop

The amplifier's fans normally stay off (speed 0) and speed up as the heat sink warms. You can set a minimum fan speed from 0 to 5 so the fans never run slower than that, for example to keep the amplifier cooler during long digital sessions.

SpeedMeaning
0Automatic: fans off until the amplifier needs them (the normal setting)
1 to 4Fans always run at least this fast; they still speed up if the amplifier heats up
5All fans at the highest speed, always

The FAN tile shows two numbers: the speed the fans are running now, and your minimum, for example 2 / min 1. The current speed can be higher than your minimum because of temperature. To change the minimum:

  • Panel: press 0 to 5 on the FAN tile.
  • Bridge window: press F and type a number, or press + or - to step up or down.
  • Thetis button: send KPA_FAN_0 to KPA_FAN_5, KPA_FAN_UP or KPA_FAN_DOWN.
Fan changes are allowed at any time, including while transmitting. They are read back from the amplifier to confirm. Reading the fan speed needs firmware 01.47 or newer. The amplifier also has a fan dwell time (menu FAN SPEED DWELL) that stops the fans changing speed too quickly; the bridge does not change it.

12. The LP-100A power metertop

  1. Connect the meter to the PC by USB. In Device Manager > Ports note its COM number.
  2. Install the serial add-on once: py -m pip install pyserial.
  3. In the panel click Settings, type the port (for example COM5) in the LP-100A port box, and press Connect. Or press L in the bridge window.
  4. Leave the meter on its Watts screen, or no data is sent.
  • Baud rate: 115200 (use 38400 for LP-100A firmware older than 1.2.0.0).
  • You can change the port at any time without restarting. The choice is remembered.
  • Disconnect turns it off. The Alarm and Mode tiles press the meter's own buttons.
  • First-time check: start with --lp100-debug to log the raw data the meter sends.

The LP-100A shows the real antenna values: true power, SWR, reflected power, return loss and impedance. The amplifier's own readings sit beside them for comparison.

13. FlexControl tuning knobtop

The FlexRadio FlexControl (FlexKnob) is a USB tuning knob with a push switch and three buttons. The bridge reads it directly and controls Thetis through the same TCI link it already uses - no DDUtil and no virtual serial ports needed. It works with or without the amplifier.

  1. Plug the knob in. If DDUtil (or another program) uses it, remove it there or close that program - only one program can use the knob.
  2. In the browser panel open Settings > FlexControl tuning knob. With Find it automatically the bridge finds the knob by its USB id; or choose a COM port yourself.
  3. The status line says 'Knob connected on COMx'. Press a button: 'last:' shows what arrived and that row lights up.
  4. Choose a function for each press, or keep the defaults. Try runs a function as if you pressed it.

Turning the knob does what the knob's mode says. A press can switch the mode; the LEDs show it. Modes: VFO A tuning (LEDs 000); VFO B tuning (LEDs 101); AF volume (master) (LEDs 100); AGC gain (RX1) (LEDs 010); RIT (10 Hz per click) (LEDs 001); XIT (10 Hz per click) (LEDs 011); Tuning step size (LEDs 110); TX drive (LEDs 111). VFO and RIT/XIT use Thetis' own tuning step; spun fast, the VFO moves faster (Fast spin). Back to VFO A after returns to VFO tuning by itself when the knob is not touched.

Custom command: choose 'Custom command' and type a Thetis CAT command (e.g. ZZMA1; = mute on, ZZTU1; = TUNE on) or a TCI command (e.g. mute:true;). Thetis' CAT command list is in its Setup > CAT Control help.

KPA1500 Knob window in Thetis: a third Thetis window shows, at a glance, what the knob does: KNOB: AF volume (master) and one short line each for the knob press and buttons 1-3, for example B1 tap >AF 2x >AGC hold Mute (>AF = the press switches the knob to AF volume; 2x = double tap; hold = long press). The lines change as the mode changes. Choose its title ({ver} = bridge version), its lines and their order, or switch it off, under Settings > Thetis windows > Knob window, then press Rebuild Thetis windows. The panel's Thetis look shows it too.

The CAT functions use Thetis' TCI command run_cat_ex. If Settings says 'Thetis does not run CAT commands over TCI', update Thetis. MOX on a knob button really transmits; it is refused while the 'no antenna?' warning shows.

14. Powering the amplifier on remotelytop

A sleeping KPA1500 cannot be woken by an ordinary command. The bridge sends a Wake-on-LAN packet and then asks the amplifier to switch on.

  1. In the amplifier menu set NET WAKE on LAN to ON, or press Enable Wake-on-LAN in the panel while the amplifier is awake.
  2. Run the bridge once while the amplifier is on. It learns the amplifier's MAC address and saves it. (Or give it with --amp-mac.)
  3. Press ON in the panel, P in the window, or send KPA_POWER_ON.

The result appears in the window and in the log. If it fails, check the NET WAKE on LAN setting, the MAC address, and that the PC and amplifier are on the same network.

15. Thetis, Thetis HL2 and SDR-VST3top

The bridge works with three versions of Thetis, one running at a time (they all use TCI port 50001 and the same radio): Thetis, Thetis HL2 (MI0BOT's version for the Hermes Lite 2) and SDR-VST3 (a Thetis version with VST plugin hosting). Nothing in the bridge has to be changed to switch between them: it connects to whichever one is running.

Getting each program ready (once)

  1. Start the program the usual way. Thetis HL2: always use its own shortcut. It starts Thetis with -dbid:HL2, which keeps its settings separate from your normal Thetis.
  2. Open Setup > Serial/Network/Midi CAT, Network tab, TCI Server box: Bind IP:Port 127.0.0.1:50001 and tick TCI Server Running. Leave the other boxes as they are.
  3. Click Apply, then OK, and close the program normally (File > Exit) so it saves.

The installer and Setup_Thetis_Containers.bat check this and print a note when the TCI server is switched off.

The KPA1500 windows in each program

  • Setup_Thetis_Containers.bat asks which program(s) to set up when more than one is installed: type a number, several like 1,3, or A for all of them.
  • Each program gets its own backup: thetis_backups (Thetis), thetis_backups\Thetis-HL2 and thetis_backups\SDR-VST3. Undo_Thetis_Containers.bat also asks which program.
  • SDR-VST3 keeps the windows in a newer format than Thetis. The setup writes that format for it automatically; nothing is different for you.
  • From a command prompt: py kpa1500_thetis_setup.py --program vst3 (or thetis, hl2, thetis,hl2, all).

Where they live

  • Thetis: C:\Program Files\OpenHPSDR\Thetis, settings in %APPDATA%\OpenHPSDR\Thetis-x64
  • Thetis HL2: C:\Program Files\OpenHPSDR\Thetis-HL2, settings in the same Thetis-x64\DB folder, as a separate database (HL2_dbman_settings.json)
  • SDR-VST3: C:\Program Files\OpenHPSDR\SDR-VST3, settings in %APPDATA%\OpenHPSDR\SDR-VST3-x64
All three run as Thetis.exe, also in Task Manager. The setup and the installer tell them apart by their folders and close only the one being changed (always the normal way, never forced). Close them yourself with File > Exit too: a program ended in Task Manager does not save, and can leave the radio or the sound device stuck until the radio is switched off and on or the PC is restarted.
Before updating or adding a Thetis version, copy the folder %APPDATA%\OpenHPSDR somewhere safe (for example C:\RadioScripts\Thetis_Backups). It holds the settings of all of them.

16. The Thetis windows (meters and buttons)top

The package includes two ready-made Thetis windows, called containers. They float on top of Thetis; drag them wherever you like or dock them into the Thetis screen.

Put them into Thetis (one double-click):

  1. Make sure the bridge is installed (the installer does this).
  2. Thetis must be closed while the windows are added, because it saves its own settings when it closes. If it is running, the setup offers to close it for you (the normal way, like File > Exit, so nothing is lost) and afterwards offers to start it again.
  3. Open the bridge folder (normally C:\RadioScripts\KPA1500_Thetis_Bridge) and double-click Setup_Thetis_Containers.bat.
  4. A black window shows what it found. Answer the questions: press Enter to accept the answer in brackets. It asks whether you use an LP-100A, then whether to make the changes.
  5. When it says Done, press a key to close the window.
  6. Start the bridge (if it is not running), then start Thetis. The two windows appear.

What the setup does for you:

  • Saves a backup of your Thetis settings first (folder thetis_backups next to the bridge).
  • Makes the two Multi Meter I/O entries the bridge needs, if they are missing: readings in on 127.0.0.1:50100 and button presses out to 127.0.0.1:50101. If you already made them, it uses yours.
  • Adds (or updates) the KPA1500 Telemetry and KPA1500 Controls windows. Running it again later updates them and keeps them where you put them.
To undo: double-click Undo_Thetis_Containers.bat (it offers to close Thetis for you). It puts back the settings saved just before the last setup.

Your own layout: in the browser panel open Settings > Thetis windows. For the Telemetry window choose which lines and bars it shows and in which order (status line, AMP frequency line, forward / SWR / drive bars, the text lines, the LP-100A bars and line, a Title line and blank lines). For the Controls window move buttons with the arrows, take out the ones you never use (x), put them back (+), add a blank space, and choose 3 to 6 columns. Each window has a Title you can type, for example KW4EX {ver} Amp - {ver} shows the bridge version (if the Telemetry title shows it, the AMP line leaves it out). The panel's Thetis look shows the result at once. To put it into Thetis press Rebuild Thetis windows: the setup window offers to close Thetis for you, makes a backup, rebuilds both windows (they keep their place) and offers to start Thetis again. Double-clicking Setup_Thetis_Containers.bat does the same. Standard order puts the layout above back.

The line under the title shows the amp power, mode, fan speed (current and minimum) and fault.

No antenna? line (red, near the bottom of both windows, blank when all is well): shows ANTENNA? RX -119 dBm (40m limit -105) when the receive level is too low, and !! TX - NO ANTENNA? CHECK DUMMY LOAD !! if you transmit anyway. See the section No antenna? check. The receive level itself is on the green AMP line.

Amp frequency line (green, in both windows), for example AMP 14.025 MHz RX -78 dBm v2.23: the frequency the amplifier itself reports it is on, read back from the amp after every VFO change. Turn the VFO and watch it follow. Nothing extra is shown while the amp is on the radio frequency; radio 7.150 ! means it is NOT (it shows where the radio is). The Telemetry line ends with the bridge version, and the Controls title shows it too (KPA1500 v2.23 Controls). (sent) means the amp does not report its frequency, so the line shows what the bridge sent. Thetis buttons cannot show changing text, so this is a text line rather than a button. If the windows were set up before this line existed, run Setup_Thetis_Containers.bat again (Thetis closed) to add it, and make the windows a little taller if the bottom is cut off.

KPA1500 Telemetry

  • Top line: amp power, mode, ATU and antenna. Under it, the green amp frequency line.
  • Bars: KPA1500 forward power, KPA1500 SWR, drive power, LP-100A power and LP-100A SWR. The live reading is a blue bar that turns red past the limit (1500 W, or SWR 2.0).
  • Peak hold: a yellow band beyond the blue bar shows the highest reading of the last 4 seconds, with a red line at its end and the peak value on the right. On a steady carrier (TUNE) the peak equals the live reading, so there is no yellow band.
  • Text lines: reflected power, gain, where the drive figure comes from; PA temperature, volts, amps and fan; fault and Standby-on-Tune; LP-100A R, X, |Z| and return loss.
  • SWR reads 1.0 when there is no RF (the amp keeps its last SWR otherwise).
If the bridge stops, a red line BRIDGE NOT RUNNING - data frozen appears at the bottom of both windows within about 5 seconds, and the Controls buttons go dark. Readings shown are then old and the buttons do nothing. Start the bridge again and everything comes back. While all is well that bottom line is simply blank.

Safety options for the AMP button are in the browser panel under Settings (or keys K and B in the bridge window): Allow Thetis to power off the amp and Block power off while transmitting. Untick the second one only if you want an emergency power-off to work even while the radio is stuck in transmit.

Changing the look: Thetis lets you change colours, fonts and sizes in Setup > Appearance > Meters/Gadgets. Running the setup again resets the two windows to the standard design. Save your own version first with the container Save button there if you change them.

22. If something goes wrongtop

What you seeLikely cause and fix
TCI:-- in the status lineThetis is not running, its TCI server is off, or the port differs. Start Thetis, switch TCI on, check --tci-port.

23. Safety notestop

  • The bridge never keys the transmitter and never presses TUNE for you.
  • ATU and antenna changes are refused while RF is present. Power-off is too, unless Block power off while transmitting is turned off for emergency shutdown.
  • Standby-on-Tune is a convenience, not a substitute for proper hardware protection.
  • Test new settings with --dry-run first, and use a dummy load for first transmissions.
  • Do not open the panel to your network without --web-token.
  • The bridge is not made by or supported by Elecraft, Telepost or the Thetis authors.
