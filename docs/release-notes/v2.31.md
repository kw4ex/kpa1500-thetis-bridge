# KPA1500 Thetis Bridge 2.31

A Windows program that connects an **Elecraft KPA1500** amplifier (and, optionally, a **FlexControl** knob and a **Telepost LP-100A**) to **Thetis**, **Thetis HL2** or **SDR-VST3**: the amp follows the radio, safe TUNE, Standby-on-Tune, "No antenna?" warning, meters and lit buttons inside Thetis, a browser panel, FlexControl knob support.

Using NereusSDR, or want the Applet window? The newer [KPA1500 SDR Bridge](https://github.com/kw4ex/kpa1500-sdr-bridge/releases/latest) replaces this program. Run only one of the two.

## How to download (no GitHub account needed)

1. Look at the **Assets** list at the bottom of this page.
2. Click **KPA1500_Bridge_Complete_v2.31.zip**. Your browser saves it, normally in your **Downloads** folder.
3. **Do not click "Source code (zip)" or "Source code (tar.gz)"**. Those are for programmers.
4. In Downloads, right-click the file, then **Extract All…**, then **Extract**.
5. Open the extracted **KPA1500_Bridge** folder and double-click **1_RUN_THIS_Installer.bat**. If Windows says "Windows protected your PC", click **More info**, then **Run anyway**. Answer the questions; press Enter to accept the suggested answer.
6. Start the bridge from the Desktop shortcut **KPA1500 Bridge**, then start Thetis.

Updating: download a newer version the same way and run its installer; choose **Keep your current options**. To go back to an older version, open the [Releases page](https://github.com/kw4ex/kpa1500-thetis-bridge/releases) and download that one.

The `KPA1500 Thetis Bridge - Overview.pdf` file in the Assets list is a one-page summary.

Needs: Windows 10 or 11, Thetis 2.10.3.12+ (HL2 2.10.3.15+, or SDR-VST3 5.x) with TCI on, the KPA1500 on your network, Python 3.8+ (the installer offers to install it).
